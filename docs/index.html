One small prompt, strict shapes.

The whole mechanism is TLDR.md: 2,218 bytes of hard caps and answer shapes. Agents with skill, hook or slash-command systems can layer more on top.

Hard caps

No preamble, no recap, no “Sure! I'd be happy to help.” A second sentence exists only when you ask or correctness demands it. Fragments are fine, articles are dropped, technical terms stay exact.

1sentence by default
3word target
6word hard max

Answer shapes

The prompt dispatches on the kind of question.

  • confirmYes. / No.
  • greetingone word
  • errorcause + fix
  • code, regex, SQLartifact only

It knows when to stop

Security warnings, irreversible-action confirmations and ambiguous multi-step sequences drop compression and get full sentences. It resumes once the risky part is over.

Code is never compressed

Code blocks, commits, PR descriptions, CLI flags and error strings stay verbatim. TLDR changes prose style only, never tools, logic, reasoning or safety.

Style, not language

Replies stay in your language. TLDR never forces an English opening, and code and API names stay verbatim.

▲Where TLDR wins

  • Long, chatty outputs. Explanations, reviews and debugging walkthroughs; the historical 60–87% cuts happened here.
  • Long sessions. Per-reply savings compound while the fixed per-turn overhead stays flat.
  • Reading speed. Shorter replies land sooner, whatever the billing model.

▼Where TLDR loses

  • Already-terse workloads. The injected rules cost roughly 0.4–1.5k input tokens per turn; save less output than that and you pay for it.
  • Per-request billing. A shorter answer is the same request; only the reading-speed win survives.
  • Session totals. Input tokens dwarf output tokens in agentic coding. Never expect the headline % on your bill.

Full cost and benefit table, net-negative cases, and how to A/B it yourself: HONEST-NUMBERS.md.

A full stack, if you want it.

The prompt works alone. Agents with plugin or hook systems can install the rest, and each piece is optional.

SessionStart activation, mode tracking (/tldr lite|full|ultra|wenyan, stop tldr) and a [TLDR] status badge for Claude Code. Codex, Cursor, Grok, Antigravity, ZCode and Pi get native hooks too. Hook downloads are verified against a published SHA-256 manifest.

Two paths. Both under a minute.

Prompt-only needs no Node. The full installer detects your agents and wires plugins, hooks and skills per agent. Full docs in the install guide.

npx -y github:0p9b/TLDR -- --all

Node 18 or newer. Auto-detects installed agents; --all adds hooks, per-repo init and optional extras. node bin/install.js --list prints the 41-agent matrix.

curl -fsSL https://raw.githubusercontent.com/0p9b/TLDR/main/install.sh | bash -s --

No Node required. Writes TLDR.md to seven standard agent config paths and installs /tldr where supported. Preview the script first; it's short. To verify afterwards:

for p in ~/.claude/CLAUDE.md ~/.gemini/AGENTS.md ~/.codex/AGENTS.md \
         ~/AGENTS.md ~/.config/opencode/AGENTS.md \
         ~/.factory/AGENTS.md ~/.pi/agent/AGENTS.md; do
  [ -f "$p" ] && grep -q "^## Prime directive" "$p" && echo "✓ $p" || echo "✗ $p"
done
/plugin marketplace add 0p9b/TLDR
/plugin install tldr@tldr

Run inside Claude Code. Ships the skill suite, slash commands and hooks as a plugin; /tldr then toggles the mode live.
